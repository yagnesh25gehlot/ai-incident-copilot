# SCOPE GUARDRAILS

The project must remain finishable in 14 days.

## Spend time on

- understanding core AI-engineering primitives
- implementing important concepts at least once
- measuring retrieval/model behavior
- debugging real failures
- production tradeoffs
- interview explanation

## Do not spend time on

- polished frontend
- CSS/design
- huge datasets
- perfect abstractions before they are needed
- cloud architecture that can be simulated locally
- exhaustive hyperparameter tuning
- 20 alternative frameworks
- premature microservices
- advanced topics before the core checklist is complete

## Rule

If an extra feature does not materially improve:
1. implementation understanding,
2. a production tradeoff,
3. an interview answer, or
4. evidence/measurement,

defer it.
